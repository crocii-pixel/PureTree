# BTC 장세 판정 차트

백테스트 창의 **기간 → BTC 차트 보기**에서 공용 글로벌 BTC/USD 정본을
확인한다. 차트와 백테스트는 동일한 시간 간격·판정 설정·데이터를 사용한다.

공용 정본이 없는 새 설치에서는 먼저 `python -m tools.download_global_btc`를
한 번 실행한다. 차트는 국내 거래소 가격으로 판정 신호를 대체하지 않는다.

## 차트 조작

- 시간 간격: `1m/15m/30m/1h/2h/3h/4h/D/W/M`
- 전체기간은 메모리 안전을 위해 `D/W/M`만 허용한다. 전체기간에서 분·시봉을
  누르면 일봉으로 유지하며, 분·시봉은 먼저 유한한 기간을 선택해야 한다.
- `W/M`은 확정 일봉만 집계하며 양 끝의 불완전 봉은 제외한다.
- 간격별 확대·이동 상태를 따로 기억한다. 간격을 왕복하면 이전 화면으로 돌아온다.
- 마우스 휠: 시간축 확대·축소. 월봉은 최소 6봉까지 확대된다.
- 왼쪽 드래그: 드래그 중 현재 화면 스냅샷을 이동하고 마우스 버튼을 놓을 때
  최종 시간 범위를 한 번만 반영한다.
- 하단에는 백테스트 기간과 현재 화면 범위를 별도로 표시한다.

## 독립 장세 판정

상승장 찾기와 하락장 찾기는 각각 하나의 방식을 선택한다. 점수 가중치와 임의
판정 임계값은 사용하지 않는다.

| 방식 | 의미 |
|---|---|
| 이중 이동평균 추세 | MA60/120과 각 이동평균의 방향으로 판정 |
| 로그 MACD | 로그가격 MACD와 신호선의 위치로 판정 |
| 변동성 돌파·이탈 | 동적 K 상단 돌파와 하방 이탈 상태 |
| 하방 채널선 | 직전 N봉 최저선의 하락 또는 완결 종가 이탈, 하락 판정 전용 |

분류 규칙은 다음과 같다.

- 상승 신호만 활성: `상승`
- 하락 신호만 활성: `하락`
- 둘 다 활성 또는 둘 다 비활성: `안정`
- 어느 한 판정기라도 준비 데이터 부족: `판정 준비`

결정 봉 `t`의 모든 값은 `t-1`까지 완결된 봉만 사용한다. 차트에서 선택한 시간
간격은 `decision_interval`로 저장되며 백테스트도 같은 간격의 공용 정본으로
판정한 뒤 국내 실행 일자에 as-of 정렬한다.

## 장세별 백테스트 전략

상승·안정·하락 각각에 다음 전략을 선택할 수 있다.

- 주간 기간리밸런싱
- 동적 K 변동성돌파
- 동적 K + ATR 하단 예약매수
- 현금 대기

장세 이름이 아니라 실제 선택 전략이 바뀔 때만 기존 포지션을 정리한다. 전략
전환 당일은 청산만 하고 다음 거래일부터 새 전략을 실행해 일봉 내부 순서에
미래정보가 섞이지 않게 한다.

ATR 하단 예약매수는 2/4/6/8 ATR 중 하나를 선택한다. 동적 K 예산과 하단
소액 예산을 미리 분리하고, 하단 신호는 글로벌 가격으로 판단한 뒤 국내 가격은
체결 근사와 비용 계산에만 사용한다.

K·MA 글로벌 신호를 받지 못한 종목은 국내 방향 신호로 대체하지 않는다. 신규
진입만 중지하고 보유분은 마지막 확정 청산 상태를 유지해 데이터 장애 자체가
강제매도 또는 무기한 현지신호 전환으로 바뀌지 않게 한다.

장세별 라우팅은 `use_for_backtest=true`일 때만 백테스트에 적용된다. 아직
`use_for_live=true`는 검증 오류로 차단하며, 연구 설정을 저장해도 실전 주문은
기존 확인형 글로벌 MA/변동성돌파 운용에서 자동으로 바뀌지 않는다.
