시작하기 전에 · 꼭 읽어주세요

이 프로그램은 개인이 취미로 만든 실험적인 소프트웨어입니다. 상용 제품이 아니고, 검증된 금융 상품은 더더욱 아닙니다.

실제 돈으로 주문을 냅니다. 전략이 과거에 어땠는지는 측정했지만 앞으로도 그러리라는 보장은 없습니다. 시장이 과거와 다르게 움직이면 손실이 납니다. 전액을 잃어도 생활에 지장이 없는 금액으로만 시작하세요.

이 프로그램을 건네준 사람은 투자 전문가가 아니며 어떤 수익도 보장하지 않습니다. 투자 권유가 아니고, 매매 결정과 그 결과는 전적으로 사용하는 본인의 책임입니다. 판단이 서지 않으면 쓰지 않는 것이 맞습니다.

이 봇이 하는 일

변동성 돌파 전략을 자동으로 실행합니다. 하루에 한 번 종목마다 목표가를 계산해 두고, 장중에 그 가격을 넘으면 삽니다. 상승 모멘텀이 꺾이면 다음 날 봉이 바뀔 때 팝니다.

먼저 읽어주세요

이 봇은 실제 돈으로 주문을 냅니다. 과거 성과가 미래를 보장하지 않으며, 원금을 잃을 수 있습니다. 손실이 나도 감당할 수 있는 금액으로만 시작하시고, 반드시 시뮬레이션 모드로 며칠 돌려본 뒤 실전으로 넘어가세요. 이 문서 5단계에 그 방법이 있습니다.

01

준비물

  • Windows PC — 봇이 24시간 켜져 있어야 매수 시점을 잡습니다. 절전 모드를 꺼두세요.
  • 거래소 계정 — 빗썸 / 업비트 / 코인원 중 하나. 원화 입금까지 마쳐둡니다.
  • API 키 — 거래소에서 발급받습니다. 3단계에서 설명합니다.
  • 텔레그램 (선택) — 매매 알림을 받고 원격으로 중단할 수 있습니다.

소스에서 직접 빌드하려면 Python 3.10 이상이 추가로 필요합니다. 완성된 QuantBot.exe를 받으셨다면 파이썬은 필요 없습니다.

02

설치

실행파일을 받은 경우

아래처럼 폴더를 만들어 주세요. 이 구조가 중요합니다.

QuantBot\
├── .env              ← API 키 (상위 폴더에 둡니다)
└── 실전\
    ├── QuantBot.exe
    ├── config.json   ← 처음 실행하면 자동 생성
    ├── quantbot.db   ← 매매 이력
    └── logs\         ← 날짜별 로그
“Windows의 PC 보호” 창이 뜹니다 — 정상입니다

이 프로그램에는 코드 서명 인증서가 없습니다. 인증서는 발급에 매년 수십만 원이 들어서, 개인이 만든 도구에는 보통 붙이지 않습니다. 그래서 Windows가 처음 실행할 때 파란 경고창을 띄웁니다.

추가 정보 → 실행을 누르면 됩니다. 백신이 격리하는 경우도 있는데, 파이썬 프로그램을 하나의 exe로 묶는 방식(PyInstaller)이 오탐을 자주 일으키기 때문입니다. 그때는 해당 폴더를 예외로 등록하세요.

다만 이건 “믿을 만한 파일이니 경고를 무시하라”는 말이 아닙니다. 아는 사람에게 직접 받은 파일일 때만 그렇게 하시고, 출처가 불분명하면 실행하지 마세요.

왜 .env만 상위 폴더인가요

나중에 서로 다른 설정을 동시에 돌려 비교하고 싶을 때, 폴더만 하나 더 만들면 됩니다. API 키는 상위 폴더에서 공유되니 폴더마다 다시 넣을 필요가 없습니다. 7단계에서 다룹니다.

소스에서 빌드하는 경우

# 1) 소스 받기
git clone -b feat/quantbot-multi-exchange https://github.com/crocii-pixel/PureTree.git
cd PureTree\quantbot

# 2) 필요한 패키지 설치
pip install -r requirements.txt

# 3) 실행파일 만들기 → dist\QuantBot.exe 생성
build.bat
build.bat에는 한글을 넣지 마세요

cmd.exe는 실행 중인 배치 파일을 바이트 위치로 다시 읽습니다. 파일 중간에서 코드페이지가 바뀌면 그 뒤 줄이 깨져 빌드가 실패합니다. 한글 메시지와 실제 빌드 로직은 tools/build_exe.py에 있습니다.

03

API 키 넣기

거래소에서 키 발급

  1. 거래소 웹사이트 → 마이페이지 → Open API로 들어갑니다.
  2. 권한은 조회와 주문만 켜세요. 출금 권한은 절대 켜지 마세요.
  3. 가능하면 본인 PC의 IP를 등록해 다른 곳에서는 쓸 수 없게 잠급니다.
  4. 발급된 두 개의 키를 복사해 둡니다. Secret Key는 발급 시 한 번만 보입니다.
출금 권한은 켜지 마세요

봇은 매수와 매도만 합니다. 출금 기능은 쓰지 않습니다. 출금 권한이 켜진 키가 유출되면 자산이 통째로 빠져나갈 수 있습니다.

.env 파일 만들기

QuantBot.exe 옆에 있는 .env.example을 복사해 이름을 .env로 바꾸고, 상위 폴더로 옮긴 뒤 키를 채웁니다. 쓰는 거래소의 줄만 채우면 됩니다. 

# 빗썸을 쓴다면
BITHUMB_CONNECT_KEY=발급받은_키
BITHUMB_SECRET_KEY=발급받은_시크릿

# 텔레그램 알림을 쓴다면 (선택)
TELEGRAM_BOT_TOKEN=봇_토큰
TELEGRAM_CHAT_ID=내_챗_아이디

설정 창에서 직접 입력해도 됩니다. 그 경우 .env가 자동으로 만들어집니다.

05

시뮬레이션으로 먼저 돌려보기

이 단계를 건너뛰지 마세요. 설정이 잘못돼 있어도 시뮬레이션에서는 돈이 나가지 않습니다. 며칠 돌려보며 매매가 예상대로 일어나는지 확인합니다.

  1. 설정 창에서 시뮬레이션 강제를 켜고 저장합니다.
  2. QuantBot.exe를 실행합니다. 트레이(작업표시줄 오른쪽)에 아이콘이 생깁니다.
  3. 아이콘을 우클릭 → 대시보드 열기로 로그를 봅니다.
  4. 2~3일 지켜보며 목표가 계산과 매수 신호가 정상인지 확인합니다.

정상이라면 로그가 이렇게 보입니다.

06

실전 전환

  1. 봇을 종료합니다 (트레이 우클릭 → 종료).
  2. 설정 창에서 시뮬레이션 강제를 끄고 저장합니다.
  3. 거래소에 원화를 입금합니다. 종목 수 × 5,000원 이상 있어야 합니다.
  4. QuantBot.exe를 다시 실행합니다.

기본 설정에서는 봇이 정지 상태로 뜹니다. 주문이 나가지 않습니다. 텔레그램으로 /실행을 보내거나 트레이 메뉴에서 시작해야 매매가 시작됩니다.

QuantBot
⏸️ 정지 상태로 대기 중 — 주문이 나가지 않습니다.

매매를 시작하려면 /실행 을 보내주세요.

config.json의 start_paused를 false로 하면 봇을 켜는 즉시 매매가 시작됩니다. 편하지만 실행 = 거래 개시가 되니, 재시작 전에 항상 현재 상태를 확인하는 습관이 필요합니다.

봇을 껐다 켜도 안전한가요

네. 같은 날 이미 산 종목은 다시 사지 않습니다. 매매 이력을 quantbot.db에 남겨두고, 재시작할 때 거래소 잔고와 대조해 당일 상태를 복구합니다.

다만 봇을 꺼도 보유 중인 코인은 팔리지 않습니다. 포지션은 그대로 남으니, 오래 꺼둘 계획이면 직접 정리할지 판단하세요.

설정 두 가지를 동시에 비교하기

폴더를 하나 더 만들고 QuantBot.exe를 복사하면 됩니다. 설정과 매매 이력은 폴더별로 분리되고, API 키는 상위 폴더에서 공유됩니다. 

QuantBot\
├── .env
├── 실전\     ← 균등 분할
└── 검증\     ← ATR 사이징 + 시뮬레이션
텔레그램은 한 곳에서만 켜세요

여러 인스턴스가 같은 봇 토큰으로 접속하면 명령이 뒤섞이고 응답이 중복됩니다. 한 곳만 남기고 나머지는 config.json에서 "telegram_enabled": false로 꺼주세요.

문제 해결

09

반드시 알아둘 한계

이 봇은 낙폭을 줄이는 도구지 수익 기계가 아닙니다

하락장에서 강합니다. 모멘텀이 꺾이면 현금으로 빠지기 때문입니다. 대신 대세 상승기에는 뒤처집니다. 과거 검증에서 시장이 8배 오른 해에 봇은 3.4배에 그쳤습니다. 절반 이상을 포기한 셈인데, 그게 폭락을 피하는 값입니다.

규모가 커지면 성과가 떨어집니다

주문이 커지면 호가를 밀어올려 계획한 가격에 못 삽니다. 거래대금이 작은 종목일수록 심합니다. 수억 원 단위부터는 백테스트와 실제 성과가 벌어지기 시작합니다.

PC가 꺼지면 매수 기회를 놓칩니다

1초마다 가격을 확인해야 돌파 시점을 잡습니다. 절전 모드, 윈도우 자동 재시작, 인터넷 끊김에 주의하세요. 다만 이미 산 것이 임의로 팔리지는 않습니다.

세금은 계산에 없습니다

백테스트 수치에 세금이 반영돼 있지 않습니다. 실제 손익은 세금만큼 낮아집니다.

마지막으로

자동매매는 사람이 판단을 멈추는 도구가 아닙니다. 시장이 백테스트 기간과 다르게 움직이면 전략은 실패합니다. 정기적으로 로그와 잔고를 확인하시고, 이해되지 않는 매매가 보이면 먼저 멈추고 원인을 찾으세요.

10

이 봇을 쓰지 않는 게 나은 경우

좋은 도구도 맞지 않는 사람이 있습니다. 아래 중 하나라도 해당하면 지금은 쓰지 않는 편이 낫습니다.

  • 잃으면 곤란한 돈으로 시작하려는 경우 — 생활비, 전세금, 빌린 돈은 안 됩니다.
  • 손실이 났을 때 잠을 못 잘 것 같은 경우 — 과거 검증에서도 자산이 17% 줄어든 구간이 있었고, 앞으로는 더 클 수 있습니다.
  • PC를 24시간 켜둘 수 없는 경우 — 매수 시점을 놓칩니다.
  • 로그를 한 번도 안 볼 것 같은 경우 — 이상이 생겨도 모르고 지나갑니다.
  • 단기간에 크게 불리고 싶은 경우 — 방향이 반대입니다. 이 봇은 크게 잃지 않는 쪽에 무게를 둡니다.

쓰기로 하셨다면

  1. 시뮬레이션으로 최소 일주일 돌려보고 로그를 읽어보세요.
  2. 실전은 가장 작은 금액으로 시작하세요. 최소 주문금액 × 종목 수면 충분합니다.
  3. 한 달쯤 지나 내가 이 변동을 견딜 수 있는지 확인한 뒤에 금액을 늘리세요.
  4. 이해되지 않는 매매가 보이면 먼저 멈추고 물어보세요.
